# 06. 进阶与扩展方向

以下是可在现有架构上逐步拓展的方向：

## 语法层面
- 赋值增强：属性/下标赋值、复合赋值 `+= -= *= /= %=`
- 新语句：`for`、`break`、`continue`
- 函数特性：默认参数、可变参数、箭头函数式语法糖
- 模块系统：`import`/`export` 或 `include`

## 运行时层面
- 更多内建：字符串/数组高阶方法（`map/filter/reduce/slice/indexOf` 等）
- I/O 与文件：受控暴露读取能力（注意安全）
- 错误管理：栈追踪、错误类型、行列与源码片段高亮

## 性能与工程
- AST 常量折叠、尾递归优化（解释层）
- 字节码编译与虚拟机（把 AST 编译为字节码执行）
- 测试与基准：覆盖各语法特性与边界

## 学习建议
- 对照源码位置阅读：
  - 词法：`src/lexer.js`
  - 解析：`src/parser.js`
  - 执行：`src/interpreter.js`
- 每完成一处修改，添加最小示例验证行为。
